# 联网搜索技能（search_skill）

## 使用规范

1. **何时使用**：用户询问实时/时效性信息（新闻、价格、版本发布），或你不确定、知识截止后发生的事情。
2. **搜索**：调用 `searchWeb`，参数 `query` 用简短关键词（如 "qwen3.5 介绍"），不要输入整句问题。
3. **深入阅读**：搜索结果中挑最相关的 1-2 个网址，调用 `fetchWeb`（参数 `url`）获取正文；搜索结果里的摘要通常已够回答，无需每条都抓。
4. **回答要求**：
   - 用中文总结，标注信息来源（网站名或网址）
   - 多条结果相互矛盾时如实说明
   - 搜索无结果时直接告知用户，不要编造

## 示例流程

```
用户: qwen3.5 有什么新特性？
→ searchWeb(query="qwen3.5 新特性")
→ （如摘要不足）fetchWeb(url="https://...")
→ 总结并附来源回答
```
